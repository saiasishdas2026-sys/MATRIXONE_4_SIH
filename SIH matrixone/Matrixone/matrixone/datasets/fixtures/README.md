# MATRIXONE Prototype Datasets — DEMO / SIMULATED

No real CPSE SAP/ERP data is included. All rows are synthetic with
realistic Indian procurement terminology for SIH demo only.

- `cpse_master.csv` — 6 CPSEs (ONGC/IOCL/CPCL/NTPC/SAIL/CIL)
- `material_master.csv` — ~1500 rows, intentionally overlapping across CPSEs
- `procurement_history.csv` — 300 sample rows for savings/analytics
- `matching_labels.csv` — 8 labelled pairs (identical/near/equivalent/different)
